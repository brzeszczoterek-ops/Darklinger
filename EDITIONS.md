# Darklinger Public

Public provides conversation, file and browser tools, coding assistance, local model management, memory, and restricted generated-tool execution.

This distribution contains only its own implementation, tests, and documentation. Private extensions, credentials, runtime state, and repository history are not included. Requesting an unavailable extension fails rather than enabling it.

Full Access is a separate planned distribution for invited users; its feature selection has not yet been finalized. It is not included in this package.
